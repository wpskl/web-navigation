# web-navigation
一个简单的网页导航工具，该工具可以根据个人自己的需求，添加不同的分类，每个分类下可以创建子类。 使用非常方便、简单，很适合个人记录导航信息。

## 第二步 添加网页导航

选择需要添加导航的分类，然后在右边输入待添加的网页地址，然后在点击 添加 按钮 即可
